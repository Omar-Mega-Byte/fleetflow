## Visual language

- Dense operational typography uses 26–30 px page titles, 14 px controls, 11–12 px metadata, and tabular identifiers.
- Deep emerald denotes brand and committed actions; cyan is reserved for live/fresh telemetry, amber for waiting, and red for intervention.
- Radius stays between 4–10 px, with crisp borders and restrained elevation instead of floating rounded-card stacks.
- Motion uses 140 ms micro feedback and 220 ms structural transitions; reduced-motion removes transforms and nonessential animation.
- Every direction labels synthetic preview data, role scope, freshness, and unavailable capabilities instead of implying omniscient live operations.

The system is a cool-neutral, precision-oriented logistics interface with one emerald brand signal and disciplined state color.
